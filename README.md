# Personal Portfolio Website

A simple and responsive personal portfolio website developed as a **First Semester project** using **HTML5 and CSS3**.

The purpose of this project was to build a basic personal website while practicing fundamental concepts of web development, including webpage structure, styling, navigation, layouts, and responsive design.

## 📌 Project Overview

This portfolio website provides an introduction to me, my skills, and my work. It demonstrates my understanding of basic front-end web development concepts and serves as the foundation for my future web development projects.

## 🚀 Features

- Personal introduction section
- About Me section
- Skills section
- Portfolio/Projects section
- Contact section
- Navigation bar
- Responsive layout
- Custom CSS styling
- Simple and clean user interface

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure and content of the website.
- **CSS3** – Used for styling, layout, colors, spacing, and visual design.
